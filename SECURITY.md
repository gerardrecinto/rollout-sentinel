# Security reports

Send vulnerability reports privately to gerardrecinto@gmail.com. Include the commit or release, affected component, impact and reproduction steps. Remove credentials and private workload data before sharing logs.

The CLI and browser demo currently use simulated data and mock cluster actions. They are not a production rollout gate. Reports about misleading success results, unsafe deployment examples, release workflows and input handling are in scope.

No response-time commitment, security audit or production support guarantee is offered here. Start with the latest default branch when checking whether an issue has already been fixed.

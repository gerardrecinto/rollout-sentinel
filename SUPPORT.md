# Evaluation help

For an optional paid evaluation or a small, agreed implementation task, contact Gerard at gerardrecinto@gmail.com. Describe what you want to evaluate, the environment and the result you need. Keep credentials and private incident logs out of the first message.

Possible scopes include reviewing the simulator's gate thresholds, adding regression cases, or planning a live integration. Any implementation scope, price and availability must be agreed before work starts.

The current CLI uses synthetic metrics and mock cluster actions. Asking about help does not imply a live Kubernetes or Prometheus integration already exists. No production support, response-time commitment or service-level agreement is included.

Send suspected vulnerabilities privately to the same address. Do not post exploit details or secrets in a public issue.
